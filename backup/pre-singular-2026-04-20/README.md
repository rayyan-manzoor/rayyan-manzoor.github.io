# Backup — pre-singular site (Ember Horizon scroll layout)

Saved before switching to the beige singular-index design.

## Files
- `index.html` — previous multi-section homepage
- `style.css` — Ember Horizon theme + scroll layout
- `script.js` — crossfade hero subtitles + fade-in / nav highlight

## How to revert
Copy these three files back to the site root (overwrite the live versions), then commit and push:

```
backup/pre-singular-2026-04-20/index.html  →  index.html
backup/pre-singular-2026-04-20/style.css   →  style.css
backup/pre-singular-2026-04-20/script.js   →  script.js
```

You can also remove the later linked pages (`jana.html`, `drone.html`, `about.html`, `certifications.html`) if you no longer need them.
